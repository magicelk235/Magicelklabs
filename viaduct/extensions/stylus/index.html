Run Stylus in Safari

Stylus, custom CSS themes for any website, has no official Safari version. Safari can't load Chrome extensions: it uses its own native .appex format that must be built, code-signed, and registered with macOS. Viaduct does all of that for you.

The whole process, three steps

  1. Get Viaduct. Free for your first 2 conversions. Turn on its small Safari extension once, and it upgrades the Chrome Web Store.
  2. Open Stylus's Chrome Web Store page in Safari.
    Stylus on the Chrome Web Store →
  3. Click "Add to Safari." The store's "Add to Chrome" button becomes "Add to Safari." One click: Viaduct fetches Stylus, converts it to a native Safari extension, signs it, and installs it. Switch it on once in Safari's settings and it appears in the toolbar, like any other extension.

What's actually happening

Viaduct downloads the exact Stylus package published on the Chrome Web Store (same code, same version) and rebuilds it as a native Safari Web Extension (.appex). It handles the conversion, the code-signing, and the macOS registration that normally require Xcode wrangling and a terminal. Because the result runs inside Safari's own engine, you keep Safari's battery life. No second Chromium process runs in the background.

Safari supports the same WebExtension API family that Chrome extensions are built on, and Viaduct patches the places where Safari behaves differently, so most extensions work. Some Chrome-only APIs have no Safari equivalent, and the features built on them won't work. If an extension can't work in Safari at all, Viaduct tells you before you convert.

Questions

Is this the real Stylus, or a clone?

The real one. Viaduct converts the exact package its developers published on the Chrome Web Store and adds the fixes Safari needs to run it. Nothing is hosted or redistributed; the conversion happens locally on your Mac.

Will it stop working after a week?

On the free plan, yes: Viaduct removes converted extensions after 7 days. Viaduct Pro keeps them installed for good.

I already use Stylus in Chrome. Do my settings come with it?

Usually, if it's installed in Chrome, Brave, Edge, Arc, Vivaldi, Opera or Chromium on the same Mac. Viaduct reads its saved settings from the browser and brings them into the Safari version. Import from Chrome in Viaduct lists everything you have installed there and converts the ones you pick in one batch.

What do I need?

macOS 13+, on Apple Silicon or Intel. Viaduct is a universal app, so one download runs natively on either chip. Node is bundled inside Viaduct, so there's nothing to install. Xcode is required (free, from the App Store), with an Apple ID signed in (a free one works), because Apple offers no other way to code-sign a Safari extension on a free account. Viaduct's first-launch setup walks you through both.

What does Viaduct cost?

Free for your first 2 conversions, which Viaduct removes after 7 days. Pro is $19 one-time: unlimited conversions, and your extensions stay installed. The conversion engine is source-available (PolyForm Shield).
