Not on the list?

Viaduct isn't limited to these. It converts any extension from the Chrome Web Store, a .zip, a .crx or an unpacked folder, and Import from Chrome converts the ones you already have in Chrome, Brave, Edge, Arc and other Chromium browsers. See how Viaduct works.
