Questions

Will my Chrome extension actually work?

Most do. Before converting, Viaduct checks the extension for the browser you picked and tells you if it can't work there, for example when a file it needs is missing. Features built on Chrome-only APIs, like some OAuth sign-in flows, still won't work after conversion. If the maker ships an official Safari version, Viaduct points you to it.

What do I need to run Viaduct?

A Mac on macOS 13 or later, and Xcode, which is free from Apple, because Apple requires it to sign extensions. Viaduct's setup walks you through signing in to it once with your Apple ID (a free one works), so Safari keeps your extensions on after it quits.

A Mac on macOS 13 or later, and Firefox. Viaduct asks once for Full Disk Access so it can read your Firefox profile, and it has to stay on in Login Items so it can load your add-ons each time Firefox opens. Firefox needs neither Xcode nor an Apple ID.

Do I need to know how to code to use Viaduct?

No. Drop an extension in and get it in Safari or Firefox. Viaduct does the building and the signing.

Does Viaduct run on an Intel Mac?

Yes. Viaduct is a universal app, so the same download runs natively on Intel and Apple Silicon. There's one build, not two, and Rosetta never comes into it.

Which license do I need?

The one for the browser you use. A Safari or Firefox license makes that browser unlimited, and Mixed, the Both card, covers the two for $10 more. Pricing shows the Safari license here. I bought Viaduct Pro. What do I have now?

Mixed. Your key keeps working, and Safari and Firefox are both unlimited.

How does Viaduct keep add-ons in Firefox?

Firefox only keeps add-ons that Mozilla has signed. So each time Firefox opens, Viaduct briefly turns on Firefox's remote debugging, loads your add-ons, and turns it off again. That leaves one Firefox setting changed while you have add-ons: Firefox won't ask before a debugger connects. Viaduct tells you before your first one, and removing your last add-on puts the setting back. Firefox restarts once when the first add-on goes in, and your tabs come back.

Why isn't Viaduct on the Mac App Store?

The build tools Viaduct drives aren't allowed inside the App Store sandbox, so it ships as a notarized direct download instead. Same Apple notarization, just outside the store.
