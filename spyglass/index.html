What it previews

Markdown

.md .markdown .mdx

Rendered the way GitHub shows it, with tables, task lists, footnotes, alerts, math and Mermaid diagrams. Images next to the file show up, and wide windows get a table of contents.

Source code

.swift .py .ts .go .rs .c and more

Around 190 languages, highlighted, with line numbers. Scripts without an extension are recognized by their shebang line, and Makefiles work too.

JSON, XML and friends

.json .xml .plist .yaml .toml .mobileconfig

Minified JSON comes out indented, keys in their original order. Binary plists show as XML, and signed configuration profiles are unwrapped first.

Notebooks

.ipynb

Jupyter notebooks show their markdown cells, highlighted code, plots, HTML tables, LaTeX and colored error tracebacks.

Diffs

.diff .patch

Colored hunks with a tab for each file, and badges for files that were renamed, added or deleted.

SQLite

.sqlite .db

Every table and view with its column types, showing the first 500 rows of each.

Tables

.tsv .jsonl .ndjson

TSV and JSON Lines files open as a table you can sort, up to the first 10,000 rows.

Archives

.zip .tar .gz .tgz .bz2 .xz .iso

See the file tree inside zip, tar, gzip, bzip2 and xz archives and ISO images without extracting anything.

Packages

.jar .war .apk .aab .whl .nupkg .vsix .xpi

Java, Android, Python, NuGet, VS Code and Firefox packages list their files, with the package name and version on top.

Apps and installers

.app .ipa .pkg .dmg .framework

Version, bundle ID, code signature and entitlements. An .ipa also shows its provisioning profile.

Binaries

Mach-O, .dylib .o .a, ELF

Architectures, minimum macOS, linked libraries and signing for executables, dylibs, object files and static libraries. ELF files get the basics.

Folders

any folder

A Finder-style list with icons, plus how many items it holds and their total size.

Torrents

.torrent

The file list, trackers, piece size and info hash.

Questions

Which Macs does it run on?

Any Mac running macOS 14 Sonoma or later.

How does the free trial work?

The 7 days start the first time you open Spyglass, and every format preview works during that week. You don't need a card or an account.

When the week is up, those files fall back to plain text or a short file summary with a note, until you add a license. Google Drive cards stay free either way.

How do I activate my license?

Your Gumroad receipt has a license key in it. Click the Spyglass icon in the menu bar, paste the key and click Unlock. The same key works on each of your Macs.

I bought Spyglass 1.0. What do I get?

Pro + Drive, free, for life. Your 1.0 key keeps working in 2.0 and unlocks every format preview along with the rendered Google Drive previews. If Spyglass ever asks for it, paste the key from your original receipt.

What happens if I cancel Pro + Drive?

You can cancel from your Gumroad receipt whenever you like, and everything keeps working until the end of the period you've paid for. After that, Drive files go back to the free card, and format previews need a Pro license.

Why do CSV and .txt files look the same as before?

macOS keeps those two types for its own preview and never passes them to a Quick Look extension, so no app can take them over. TSV and JSON Lines files do get Spyglass's table view.

Space still shows the old preview. What's wrong?

First, check that Spyglass is in your Applications folder and that you've opened it once. If another Quick Look app is installed, it may be handling the same file types, and macOS only uses one extension per type.

On macOS 15 or later, open System Settings → General → Login Items & Extensions, find Quick Look under Extensions and turn off the other app's extension. On macOS 14 the same list is under System Settings → Privacy & Security → Extensions → Quick Look.
